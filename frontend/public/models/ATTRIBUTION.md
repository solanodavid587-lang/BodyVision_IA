# Atribución y licencia del modelo 3D

El activo `skeleton.glb` procede de [3d-human-body-anatomy](https://github.com/SeemaBansal1/3d-human-body-anatomy), cuyo README atribuye los modelos a [Z-Anatomy](https://www.z-anatomy.com/) y a la base [BodyParts3D](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/).

El README del repositorio indica licencia **Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)** para los modelos derivados. Si se redistribuye o adapta este activo, conservar la atribución y cumplir la condición ShareAlike. El visor usa únicamente el esqueleto; no incluye la capa de órganos, que el README advierte contiene un modelo de riñón con licencia CC BY-NC 4.0.

Esta atribución es una referencia de integración, no una revisión legal. Confirmar los archivos de licencia y las condiciones vigentes del autor antes de publicar o usar BODYVISION AI comercialmente.
